# Weisiger Group — homepage redesign

A static, single-page redesign concept for [weisigergroup.com](https://www.weisigergroup.com), using the visual and UI style of waterplan.com as a reference (navy and bright-blue palette, Golos Text, floating pill navigation, curved hero, alternating feature rows with floating info cards, large rounded dark panels).

All copy and company information come from Weisiger Group's current website. Company logos are the web versions from weisigergroup.com.

## Run it

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## Structure

```
index.html          the page (HTML + inline styles)
assets/logos/       Weisiger Group and company logos
```
